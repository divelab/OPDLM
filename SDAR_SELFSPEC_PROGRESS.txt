SELF-SPECULATIVE EVALUATION RESUME NOTE (updated 2026-07-30)

Status: OPDLM and SDAR K=4 self-speculative implementations and full HumanEval/LCB-v6 comparisons are complete.

LCB-v6 matched setting
- Models: OPDLM-4B and JetLM/SDAR-4B-Chat
- Dataset: existing LCB_v6 pipeline, 454 problems
- Decoding: greedy self-speculative, K=4, max_new_tokens=8000
- Execution: 8 GPU shards, one response/problem, existing LCB private-test evaluator

Verified LCB-v6 results
- OPDLM-4B: 93/454 = 20.4846% pass@1
  - acceptance: 81.5848%
  - accepted draft tokens/iteration: 3.2631
  - generated tokens/iteration: 3.5994
  - conceptual tokens per draft+verify forward: 1.7997
  - total generated tokens: 569,299
- SDAR-4B-Chat: 61/454 = 13.4361% pass@1
  - verified independently by shard: 8 + 12 + 8 + 4 + 7 + 13 + 4 + 5 = 61
  - acceptance: 90.9388%
  - accepted draft tokens/iteration: 3.6371
  - generated tokens/iteration: 3.8002
  - conceptual tokens per draft+verify forward: 1.9001
  - total generated tokens: 158,810
- OPDLM advantage under matched self-speculation: +32 solved problems, +7.0485 absolute accuracy points, about +52.4% relative accuracy.
- Important interpretation: SDAR has higher acceptance/tokens-per-forward but much lower accuracy. Self-agreement is not evidence of retained code capability.

LCB-v6 result locations
- OPDLM: pure_inference/results/OPDLM-4B_LCB_v6_selfspec_k4_guard005_8gpu_8k_lcbv6/
- SDAR: pure_inference/results/SDAR-4B-Chat_LCB_v6_selfspec_k4_8gpu_8k_lcbv6/

HumanEval matched results
- OPDLM-4B self-spec K=4: HumanEval 73.78% (121/164), HumanEval+ 70.12% (115/164), acceptance 83.32%, generated/iteration 3.64, conceptual tokens/forward 1.82.
- SDAR-4B native K=4: HumanEval 75.61%, HumanEval+ 66.46%.
- SDAR-4B self-spec K=4: HumanEval 79.27% (130/164), HumanEval+ 71.34% (117/164), acceptance 87.47%, generated/iteration 3.73, conceptual tokens/forward 1.86.
- Therefore the earlier hypothesis that SDAR would regress under self-speculation is false on HumanEval.

Implementation completed
- sample/self_speculative.py contains OPDLM KV-cached self-speculation and SDAR position-aligned self-speculation.
- sample/sdar_rl_rollout.py has an evaluation-only self-speculative path.
- pure_inference/eval.py permits self_speculative for bd3lm and sdar.
- reward/pyext.py is a permanent local RuntimeModule implementation required by LCB.
- reward/rl_execute.py evaluates LCB submissions in bounded batches to reduce nested-multiprocessing exhaustion.

Evaluator caveat
- Monolithic LCB scoring produced invalid 0% results because the evaluator nests ProcessPoolExecutor, multiprocessing.Manager, and one process per submission.
- Both final LCB scores above were verified using independent per-shard scoring. The SDAR shard counts are explicitly recorded above.
- Pathological submissions can still hold a worker for nearly (timeout + 1) * number_of_tests + 5 seconds. A future cleanup should enforce a bounded outer per-submission wall timeout and terminate/join the full process tree without changing the six-second per-test limit.

Scientific caution / next required control
- Do not claim SDAR fails to benefit from self-speculation based only on the comparison above.
- Run matched native SDAR LCB-v6 before claiming an SDAR self-speculative delta.
- Defensible current claim: under the same K=4 self-speculative evaluation, OPDLM-4B substantially outperforms SDAR-4B on LCB-v6 despite SDAR having higher token acceptance and nominal tokens/forward.
